# small-llm-lab

Three hands-on tasks with small open-weight language models.

| Folder | Task |
|---|---|
| `task1-lora-finetuning/` | Fine-tune a small model (≤ 1.5B params) with LoRA/QLoRA and compare it to the base model on a held-out test set |
| `task2-rag-from-scratch/` | Question answering over a public document set using only an embedding model and NumPy/FAISS |
| `task3-local-inference/` | Run a small model locally at two quantisation levels and compare speed, memory and output quality |
| `report/` | Final PDF report (max 4 pages) |

Each task folder has its own README with setup and run instructions.
